
# Lab 6 — Code and Branch Coverage

## About

This lab focuses on code coverage and branch coverage testing of a Python-based Phone Repair Quote application using **Pytest** and **Coverage.py**.

The application calculates repair quotations based on the phone part, brand tier, warranty status, and express service. It also estimates repair turnaround time and calculates trade-in values.
